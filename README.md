# Telco Customer Churn Analysis

## Project Overview

This project analyzes customer churn in a telecommunications company using Python, SQL, and Power BI. The goal is to understand customer churn patterns and identify factors associated with customer retention.

## Tools and Technologies

- Python – Data cleaning and exploratory data analysis (EDA)
- Pandas – Data manipulation and preprocessing
- MySQL – SQL queries and business analysis
- Power BI – Interactive dashboard and data visualization

## Project Files

| File | Description |
|---|---|
| `churnPy.ipynb` | Python data cleaning and EDA notebook |
| `churn.sql` | SQL queries for customer churn analysis |
| `newPr.pbix` | Power BI interactive dashboard |

## Analysis Performed

- Overall customer churn rate
- Churn by contract type
- Churn by internet service
- Churn by payment method
- Churn by tech support
- Churn by customer tenure
- Customer and revenue analysis

## Key Objectives

- Clean and prepare customer data for analysis.
- Explore customer churn patterns using Python and SQL.
- Build an interactive Power BI dashboard to visualize findings.
- Practice practical data analytics skills and business reporting.

## How to Use

1. Download or clone this repository.
2. Open `churnPy.ipynb` in Google Colab or Jupyter Notebook.
3. Run the SQL queries in `churn.sql` using MySQL with the required dataset.
4. Open `newPr.pbix` in Microsoft Power BI Desktop.
